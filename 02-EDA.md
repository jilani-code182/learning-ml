# EDA 

## What is EDA? 

EDA means understanding the dataset before building the ML model 

## Steps of EDA

### 1. Viewing the Data 

In this step, we see what columns do we have and what types of data are there in those columns. 

> NOTE:
>
>  We use functions like: `head(), tail(), shape, info()` for data viewing. 


### 2. Summary Statistics

In this step, we take a quick overview of data, see how data are spread and we see its central tendency as well. 

>NOTE:
>
> We use properties like: `mean, median, mode, std, min, max and quartile` for overviewing data.


### 3. Value Count

In this step, we see how many unique value are in the column. It is great for categorical (qualitative) data.

### 4. Missing Value Analysis
In this step, we see where are the gaps in our data and how much percent of our data is missing.

### 5. Data Visualization 

We do visualizations of data in this step. Following are the types of visualizations we do:


| Visualization | Purpose |
|---|---|
| 📊 **Histogram** | Shows the **distribution of values** |
| 📦 **Box Plot** | Identifies **outliers and spread** |
| 📊 **Bar Plot** | Compares **categorical values** |
| 🔥 **Correlation Heatmap** | Shows **linear relationships between numerical features** |
| 🔵 **Scatter Plot** | Shows **relationships between two variables** |

<br>

### 6. Target Variable Exploration

We explore the output variable and find its relation with other variables.

## Importance of EDA

- Helps to understand the data before cleaning and preprocessing
- Helps to identify mistakes and biases in the data
- Guides the direction of data cleaning and feature engineering
- Help to give an overview of data to our audience, it shows what data is telling to you
